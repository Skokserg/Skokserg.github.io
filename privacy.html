PRIVACY POLICY

Privacy and data handling

Effective: October 11, 2026

PersonalCloudMigration is a non-commercial, private workflow that uses rclone to copy files from a personal Yandex Disk account into a personal Google Drive account. The operator and user are the account owner. The workflow runs on a privately administered virtual private server (VPS). This public GitHub Pages website only explains the utility and does not request Google sign-in or process your files.

1. Google user data accessed

With authorization, the utility may access Google Drive folder metadata, file names, identifiers, sizes, timestamps, checksums when available, and file contents for verification. It creates destination folders and files and checks existing copies to avoid redundant transfers. The Google Drive scope https://www.googleapis.com/auth/drive may be requested because the utility must access an existing archive created under a different OAuth client, not just files created by the current client.

2. Purposes and limited use

Google user data is used solely to copy the account owner's data into Google Drive, resume interrupted migration, identify transfer errors and verify transferred content. The workflow is not designed to delete files from the source or to use Drive content for advertising, marketing, credit decisions, profiling, training AI models or any unrelated purpose.

3. Processing and storage

Files are transmitted between the cloud providers through the private VPS using encrypted network connections. The workflow does not intentionally create a permanent second archive of file contents on that VPS. Transient buffers are used for transfer. Migration logs may retain file paths, sizes, timing, statuses and error messages to diagnose failures. Copied files remain in the owner's Google Drive under the owner's control.

OAuth access and refresh tokens and other connection credentials are retained in restricted-access configuration files on the VPS for as long as needed to operate or troubleshoot the migration. The account owner may revoke Google authorization in Google Account settings and delete the local credential configuration. Migration logs and temporary information may be removed by the account owner when no longer needed.

4. Sharing and disclosure

Google user data is not sold, shared with advertisers or disclosed to other users. Data is transmitted to Google Drive as the selected destination, while Yandex Disk acts as the source. The VPS infrastructure is used as a technical transit environment. The informational website itself does not receive OAuth tokens or access to Drive files.

5. Security

Cloud connections use HTTPS/TLS; server configuration files holding credentials are restricted to privileged access. The server is managed privately and is not accessible to the public through the migration interface. No security measure can guarantee absolute protection.

6. User choice, retention and deletion

The account owner can pause or stop the transfer, revoke OAuth consent, remove credentials and logs from the VPS, and manage copied files in Google Drive. Source files in Yandex Disk remain unless the owner separately deletes them. The utility does not impose its own retention period on the owner's Google Drive files.

7. This informational website

This site is statically hosted by GitHub Pages. It has no forms, advertising pixels or application analytics scripts. GitHub may process ordinary web requests according to GitHub's own privacy practices. The site does not embed Google login or receive user files.

8. Changes and contact

This policy will be updated if the utility's data practices materially change. Questions or requests can be raised through the project's GitHub issue tracker; do not include passwords or private file contents in public issues.
