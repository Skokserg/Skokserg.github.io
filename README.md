# PersonalCloudMigration — public information pages

Static GitHub Pages site for a personal, non-commercial rclone workflow that transfers files from Yandex Disk to Google Drive.

Pages:
- `index.html` — application home page and purpose
- `privacy.html` — privacy policy
- `terms.html` — terms of use
- `style.css` — visual design

The site has **no Google OAuth secrets**, no account tokens, no files from either cloud, and no backend.

This repository is deliberately public for GitHub Pages and Google OAuth branding. No data migration takes place here.
