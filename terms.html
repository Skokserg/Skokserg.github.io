Terms of use

Effective: October 11, 2026

1. Scope

PersonalCloudMigration is a personally operated, non-commercial workflow built with rclone for transferring data between the owner's own cloud storage accounts. It is not offered as a public consumer service. This website is informational only.

2. Authorized operation

The operator must authorize only cloud accounts they control and comply with the terms of Google Drive, Yandex Disk and the hosting provider. The migration is configured to copy files without intentionally deleting the source data; the account owner remains responsible for reviewing destination contents before deleting any original files.

3. Data and account control

The account owner retains control of access permissions, tokens, destination folders, file retention and cloud billing. Permissions can be revoked at the corresponding cloud provider.

4. Limitations

Transfer speed, API availability, quotas and file compatibility depend on cloud providers and infrastructure. No guarantee is made that a transfer will complete without interruption or preserve external sharing links and cloud-specific metadata.

5. Privacy and contact

Please read the Privacy Policy for data handling details. Questions may be raised in the GitHub issue tracker. Do not post confidential account information there.
